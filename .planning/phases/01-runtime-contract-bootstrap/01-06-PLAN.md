<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| canonical payload to full admission | Readable files are untrusted until the bounded CPU process proves usable model/WAV behavior. |
| source/VAD paths to native Whisper argv | Unicode user-visible paths cross a known native compatibility boundary through private staging only. |
| staging directory to cleanup | Temporary model/audio/VAD copies must not persist or overwrite source content. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-13 | Tampering | canonical model and smoke WAV | high | mitigate | Admit only successful bounded staged transcription and reject corrupt/nonempty model or incomplete evidence before persistence. |
| T-01-14 | Denial of service | Whisper admission smoke | high | mitigate | Fixed argv, bounded validator timeout, failure evidence, repeat/interruption tests, and staging cleanup in `finally`. |
| T-01-15 | Information disclosure | temporary staging inputs | medium | mitigate | Use private application-controlled ASCII directory, byte-copy only required inputs, and cleanup on all terminal paths. |
| T-01-16 | Tampering | optional VAD argv | high | mitigate | Stage optional VAD model and assert every native filesystem argument is ASCII. |
| T-01-SC | Tampering | dependency installs | high | mitigate | No package-manager installation is authorized in this plan. |
</threat_model>

ASVS-L1 applies to local runtime integrity, native-process availability, and temporary-data protection at the canonical payload → full admission, source/VAD path → native argv, and staging-root → cleanup boundaries. Every high-severity mitigation acceptance test is execution-blocking: this plan cannot complete if any one fails.
