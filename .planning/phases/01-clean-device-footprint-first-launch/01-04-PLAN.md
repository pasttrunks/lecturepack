<objective>
Cut the two provably-unused mass sources from the packaged output — the duplicated Whisper model and
four unused Qt components — and investigate the third without touching it.

**D-01** fixes the cut scope exactly: dedupe `ggml-base.en.bin` to a single location, and remove
`translations/`, `qml/`, the Quick/Quick3D DLLs, and `Qt6Pdf.dll`. **D-02** keeps `opengl32sw.dll`.
**D-03** rejects an aggressive Qt allowlist for this phase. **D-04** makes `resources/` (102 MB)
investigate-and-report only, not pre-approved for cutting. **D-05** makes the *resolution logic* the
deliverable, not the deletion: whichever model copy survives, both the guided demo and the runtime
admission smoke must resolve it, proven by a test rather than assumed.

The mechanism question is already settled empirically. `lecturepack.spec:87` has carried
`excludes=["tkinter", "PySide6.QtQuick3D", "PySide6.Qt3DCore"]` since the file's first commit, yet the
built tree still contains `Qt63DCore.dll`, `Qt6Quick3D.dll`, `Qt6Quick3DRuntimeRender.dll` and the
whole `qml/` tree. `01-RESEARCH.md` establishes why: `excludes` filters Python-importable modules,
while these arrive as native link-time dependencies of WebEngineCore or have no Python module to name
at all. Post-build pruning is the only lever, which is the discretion CONTEXT.md already grants.

This plan depends on Plan 01-01 because that plan records the pre-cut baseline from a freshly built
installer, and `build.py main()` deletes `app/dist/` on every run. Landing this first would destroy
the "before" half of Success Criterion 1.

Purpose: remove ~380 MB of provably unused payload without weakening the runtime contract.
Output: a pruning step with tests, a deduped model, and a written `resources/` findings report.
</objective>
