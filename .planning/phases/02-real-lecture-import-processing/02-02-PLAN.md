## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| job state.json on disk | Jobs persist via filesystem; a tampered state.json could claim a wrong lifecycle state |
| controller signals -> UI | Signal payloads carry job identity; ownsPayload() guards against stale/wrong-job data |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-04 | Tampering | job state.json | low | accept | state.json lives in the user's own data directory; the lifecycle state machine (job_lifecycle.py) validates transitions and rejects illegal ones; reconcile_on_load demotes stale sessions |
| T-02-05 | Information Disclosure | _list_jobs output | low | accept | _list_jobs output stays within the app process; it is emitted only to the local WebEngine bridge, not to any external channel |
</threat_model>
