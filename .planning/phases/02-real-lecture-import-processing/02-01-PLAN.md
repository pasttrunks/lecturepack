<objective>
Fix the root cause of the "normal processing doesn't find bundled runtime" defect (D-01):
seed whisper_exe, ffmpeg_exe, ffprobe_exe into ConfigManager at boot via the existing
RuntimeBootstrapService assessment, fix start_processing()'s pre-flight gate to use
EngineRegistry.resolve() instead of a raw config read, and fix the _kick_poster() ordering
race in import_video(). These three changes close the gap between the demo path (which
works) and the normal path (which does not) on a clean install.

Purpose: This is the dependency root for all Phase 2 work. The demo bypasses
start_processing() entirely and writes its own throwaway config, so it works. Normal
processing reads config.get("whisper_exe","") which is permanently empty on a clean install
because nothing ever writes it — RuntimeBootstrapService.assess() proves the bundled binary
works but persist_runtime_health() only persists whisper_model, never the exe paths. Fixing
this one gap unblocks SC-04/05/06 (all three output modes), SC-07 (shared resolution), and
SC-08 (thumbnail on import). Per D-02, user-set paths are never overwritten. Per D-03, the
demo path is not touched.

Output: Three targeted fixes in three files, plus regression tests proving the clean-install
scenario now works and user overrides are preserved.
</objective>
