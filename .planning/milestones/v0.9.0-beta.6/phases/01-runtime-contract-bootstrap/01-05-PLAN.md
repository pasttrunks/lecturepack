<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| package source to fresh onedir | Canonical payload paths and bytes must be assembled without unintended state or missing directories. |
| validator to native executable | A local executable can fail before a process exists and must not escape into normal startup. |
| validation evidence to persistence | Incomplete or exception-derived evidence is untrusted and cannot authorize health. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-10 | Tampering | `bundle_engine()` destinations | high | mitigate | Create only canonical inventory parents, retain source/destination nonempty checks, and prove a fresh-tree assembly with clean-state validation. |
| T-01-11 | Denial of service | `RuntimeValidator.run()` process creation | high | mitigate | Capture OSError as bounded failed evidence; retain timeout/tree-cleanup behavior only when a process was created. |
| T-01-12 | Elevation | bootstrap persistence | high | mitigate | Convert validator exceptions to SETUP_REQUIRED component evidence and test no health/migration write or optional resolution. |
| T-01-SC | Tampering | dependency installs | high | mitigate | No package-manager installation is authorized in this plan. |
</threat_model>

## ASVS-L1 applicability and completion gate

ASVS-L1 applies to local startup integrity and availability at the package-source → onedir, validator → executable, and evidence → persistence boundaries. T-01-10 is controlled by the fresh-onedir assembly plus `check_clean_state()` acceptance test; T-01-11 by the failed-`Popen` SmokeEvidence acceptance test; and T-01-12 by the synthesized SETUP_REQUIRED/no-persistence/no-optional-resolution acceptance test. Every high-severity mitigation acceptance test is execution-blocking: this plan cannot complete if any one fails.
