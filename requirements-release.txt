# LecturePack OFFICIAL RELEASE dependency lock.
#
# Development installs may keep the convenient ranges in requirements.txt and
# app/requirements.txt. Official release builds must not: an installer whose
# contents drift between builds cannot be reproduced or audited after the
# fact. .github/workflows/release-electron.yml installs THIS file.
#
# This is an intentional release dependency set, not an environment dump. Only
# packages that actually ship in the installer, or that produce it, are pinned.
# Node dependencies are locked separately by electron-spike/package-lock.json.
#
# Provenance of these pins: the versions verified present in the shipped
# LecturePack 2.0.0 package (Setup.exe SHA-256
# 5c36408b31af79221329ca8e3ad54d547a319d4dba077b4be9b925676c648be6) plus the
# build host that produced it. opencv-python-headless was read back from the
# packaged cv2/version.py (headless = True) and yt-dlp from the packaged
# self-test's yt_dlp check.
#
# When bumping any pin: rebuild, rerun the packaged self-test and the packaged
# acceptance, then update this file in the same commit.
